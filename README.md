# 手机回收报价秒查

Windows 桌面软件，用于搜索数码回收网“二手手机”分类中的手机报价。软件包只包含程序，不包含行情数据；用户可单独保存或更新自己的 `data/` 文件夹。

## 下载和使用

1. 从 GitHub Releases 下载并解压 `PhonePriceSearch_Windows.zip`。
2. 将自己的 `data/` 文件夹放在 `手机回收价格秒查工具.exe` 同级目录。每个品牌一个子文件夹，报价 CSV 放入相应品牌文件夹。
3. 双击 EXE。选择报价日期，输入型号即可搜索价格。
4. 联网更新默认关闭；需要更新时勾选“联网更新”，软件会补下载本地缺少的报价。日期默认选最新报价日期。联网和代理设置保存在 EXE 同级的 `app_settings.json`。代理默认关闭，可在“代理设置”中填写 HTTP 代理 IP 和端口；关闭代理时直接使用本机网络。

离线使用时，软件需要本地 `data/` 中已有报价。首次启动没有本地数据且关闭联网时，搜索结果为空。

## 本地运行

需要 Python 3.10 或更新版本：

```bash
python -m pip install -r requirements.txt
python phone_search.py
```

## 数据格式

- 软件递归读取 `data/` 下的 CSV，支持按品牌建立子文件夹。
- 文件可包含报价日期、系列/品牌、型号及不同成色报价列；兼容已有 CSV 表头和 UTF-8、GB18030 等常见编码。
- 联网更新仅采集“二手手机”下 `p_id=1` 的品牌入口，按品牌文件夹和日期写入报价；本地已有同品牌同日期的报价会跳过，不重复下载或覆盖；不会清理用户放入 `data/` 的其他 CSV。
- `data/` 已加入 `.gitignore`，不会由 GitHub Actions 上传或放进软件 ZIP。发布工作流只生成软件 EXE 和说明文件。

报价仅供行情参考，实际价格以回收平台或回收商质检为准。
